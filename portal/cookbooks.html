Claude Cookbooks

A curated ~56 of the Claude Cookbooks (Anthropic, MIT), mapped to the CCDV-F domain and the bootcamp day each one reinforces. Each card opens the notebook rendered on GitHub (reliable, read-only), with Colab (run it) and nbviewer as alternates. Six of these are also distilled into runnable code-snippets/.

Run them locally: git clone https://github.com/anthropics/claude-cookbooks · pip install anthropic jupyter · jupyter lab. Notebooks make live API calls — set ANTHROPIC_API_KEY. Recipes reference newer model IDs; swap in claude-haiku-4-5 for classroom cost. MIT-licensed; © Anthropic.
