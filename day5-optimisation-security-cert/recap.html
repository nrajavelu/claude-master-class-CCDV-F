Model selection

  • Quality / latency / cost — pick 2. Start capable, measure, step down. Not "pick a tier by task type". Lower effort on the newest model often beats a smaller model at high effort. xhigh = coding/agentic sweet spot.

Cost & token management

  • input_tokens = your text + tool schemas + system + generated output. Read usage every call. Judge cost per completed task.
  • The order: 1 caching → 2 input hygiene → 3 loop/output hygiene → 4 batch → 5 budgets → 6 effort → 7 model → 8 multi-model. Free wins first.

Prompt caching

  • Prefix match — any byte change in the prefix invalidates everything after it. Render order tools → system → messages; stable content before the breakpoint, volatile after.
  • Verify with usage.cache_read_input_tokens (0 across repeats = something invalidating). Invalidators: datetime.now(), unsorted json.dumps, varying tool set.
  • Cache read ≈ 0.1× input price; cache write ≈ 1.25×.

Batch

  • ~50% cost, non-urgent. Poll to ended. Results come back in ANY order — key by custom_id, never position. "10,000 docs overnight, cost matters" → Batch.

Reliability — three places a call breaks

  • Before it leaves — 400, fail fast. In transit — 429 rate_limit (yours) / overloaded (theirs) / connection — back off. After 200 — truncation / refusal (check stop_details) / wrong shape (validate).
  • SDK retries 408/409/429/5xx + connection, max_retries=2. On streams, an error can arrive as an event mid-stream.

Vision & documents

  • An image is built-in tokens (patches) → if you have the text, send the text. A PDF is billed twice — text and each page as an image. Citations: citations:{enabled:true} on each document block.

Security & secrets

  • Injection: "must never" → guidance is dead. Isolate untrusted text + a blocking hook on the dangerous tool. A more capable model follows the injected instruction better too — tier is not the fix.
  • Keys in a secret store / .env + .gitignore, never the repo. Least-privilege PAT. ${VAR} expansion in config. Self-hosted ≠ air-gapped.

Exam-day routine

  • ~135 sec/item; flag & move past 2.5 min. Read the last sentence of the stem first ("best" / "select two" / "will NOT").
  • Name the decision → kill stale-API + generic-knob → if must/never, kill guidance → pick the mechanism → tie-break to cheaper/simpler/SDK-native. No blanks.
