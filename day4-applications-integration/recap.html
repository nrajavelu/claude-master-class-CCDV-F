Requirements — one sentence, two lists

  • Functional — what it does (summarise the ticket, stream the answer, read the screenshot).
  • Infrastructure — what it runs on and what the team must be able to do to it (shared server, any engineer can deploy + roll back).

Systems life cycle

  • develop → implement → operate → maintain. "Implement" = deploy where users are, not write the code.
  • Production credit is earned in operate + maintain. Who deploys → implement; who gets the 2 a.m. call → operate.

SW-eng foundations (the mechanisms)

  • Version control → rollback = pick the last good version. Code review → knowledge leaves one head.
  • Pipeline — branch → review → test → deploy. Refactoring — small (rename) & large (restructure); safe only with history + tests.
  • Rule 2: "any engineer can roll back" kills "write a setup doc" — a doc is guidance; VCS + pipeline is the mechanism.

Configuration management — same repo, 3 Claudes

  • Pin the model version. Commit CLAUDE.md. Env-specific settings in a committed config.toml/.env.example. Secrets in .gitignore.
  • Every behaviour-affecting input in version control or an example config — secrets are not.

Context engineering — a bigger window makes it worse

  • The window holds your input + tool schemas + history + the answer. A growing conversation is a growing request.
  • Compaction = summarise earlier context. Context-editing = clear old tool-results / thinking. Memory tool = write to disk. One session per task; compact when it genuinely runs long.

RAG

  • chunk → embed → similarity search → grounded prompt (<doc id>) → answer + cite. Out-of-corpus question → say so, don't invent.
  • RAG vs long-context vs fine-tune: retrieve when the knowledge is large / changing / must be cited. Embeddings: Voyage or local — no first-party Anthropic embeddings API.

Evaluation

  • Eval set (input → expected properties). Three check types: structural assertion · keyword/contains · LLM-as-judge. Wire as pytest.
  • Assert on structure + key content, not exact wording — output varies by design.
